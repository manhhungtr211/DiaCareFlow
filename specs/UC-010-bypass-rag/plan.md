# Implementation Plan: UC-010 Bypass RAG

**Input**: Feature specification from `specs/use-cases/UC-010-bypass-rag.md`

---

## Summary

UC-010 upgrades the **Supervisor node** from a pass-through into an **intent classifier** that routes safe queries to two distinct paths:

- **Small talk** (greetings, thanks, casual chat) → `response_agent` directly, bypassing vector search.
- **Diabetes / health question** → `rag_agent` → `response_agent` (existing RAG pipeline).

Harm Assessment continues to block dangerous queries (prescription, diagnosis, emergency) before Supervisor is reached — its logic is **unchanged**. The net result is lower latency and fewer LLM tokens consumed for small-talk interactions.

---

## Technical Context

**Language/Version**: Python 3.x

**Primary Dependencies**: LangGraph (`langgraph`), LangChain, `langchain_groq` (ChatGroq)

**Storage**: Qdrant (unchanged — only bypassed on small-talk path)

**Testing**: pytest + manual CLI validation (see `quickstart.md`)

**Target Platform**: Linux / Windows server (no change)

**Project Type**: LLM Agent pipeline (LangGraph `StateGraph`)

**Performance Goals**: Eliminate the vector search round-trip and chunk-assembly for small-talk queries; reduce p50 response time for greetings.

**Constraints**: Classification accuracy is the primary constraint — must not misroute diabetes questions to the small-talk path.

### 2. `src/agents/nodes/supervisor.py` — add LLM intent classification

Replace the current pass-through body with an LLM call when `is_safe=True`:

```python
# Classify intent using ChatGroq
prompt = f"""
Phân loại tin nhắn sau thành MỘT trong hai nhãn:
- SMALL_TALK: chào hỏi, cảm ơn, tạm biệt, trò chuyện thông thường
- DIABETES:   câu hỏi hoặc yêu cầu thông tin về bệnh tiểu đường / sức khỏe
Nếu là SMALL_TALK thì trả lời luôn bằng câu trả lời giao tiếp thông thường, không cần thực hiện tìm kiếm vector
Nếu ko phải thì trả về là DIABETES.
Tin nhắn: "{user_input}"
"""
# Default on error: "DIABETES" (fail-safe → RAG path)
intent = "DIABETES"
response = llm.invoke(prompt)
if "DIABETES" in response.content.upper():
    chuyển đến node RAG 
else:
    chuyển đến Response Node để trả ra luôn câu trả lời  

### 3. `src/agents/graph.py` — 3-way conditional routing

```python
from src.agents.state import AgentState, SafetyCategory

def _route_after_supervisor(state: AgentState) -> str:
    if not state.get("is_safe", True):
        return END
    if state.get("intent") == "SMALL_TALK":
        return "response_agent"   # bypass RAG
    return "rag_agent"            # diabetes query → RAG

# Update add_conditional_edges map:
graph.add_conditional_edges(
    "supervisor",
    _route_after_supervisor,
    {
        "rag_agent": "rag_agent",
        "response_agent": "response_agent",   # NEW
        END: END,
    },
)
```
