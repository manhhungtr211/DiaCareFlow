# Phase 1: Data Model

## StateOutput

The `StateOutput` represents the standardized output generated by each specialized sub-agent (Factor, Suggestion, Harm).

### Structure (Pydantic / TypedDict)

## AgentState

The core state managed by LangGraph. We use `Annotated[list, operator.add]` as reducers to fan-in the `StateOutput` results from multiple sub-agents running in parallel.

```python
from typing import Annotated, List
import operator
from langgraph.graph import MessagesState

class AgentState(MessagesState):
    # --- Input / Context ---
    user_input: str
    chat_history: List[Any]
    
    # --- Sub-Agent Tasks ---
    factor_task: str
    suggestion_task: str
    harm_task: str
    
    # --- Sub-Agent Reducer Outputs (Fan-in) ---
    factor_results: Annotated[List[StateOutput], operator.add]
    suggestion_results: Annotated[List[StateOutput], operator.add]
    harm_results: Annotated[List[StateOutput], operator.add]
    
    # --- Final Output ---
    response_context: dict
    errors: Annotated[List[str], operator.add]
```
